# COUNTRY NAME IDEAS

ชุดนี้เป็นชื่อเสนอสำหรับประเทศรองบนแผนที่ฉบับปัจจุบัน  
โทนชื่อพยายามให้อยู่ในตระกูลเดียวกับ `Lacoss`, `Velmora`, `Aetherion`, `Eryndor`, `Varelia`

## กลุ่มตะวันตก

| ตำแหน่งบนแผนที่ | ชื่อเสนอ | ฟีล |
| --- | --- | --- |
| ประเทศสีน้ำตาลใหญ่ทางตะวันตกของ Eryndor | `Rothmere` | รัฐเก่าแก่ชายฝั่ง มีที่ราบสูงและอำนาจทหาร |
| ประเทศสีเขียวอ่อนฝั่งตะวันตกติด Rothmere | `Lysenne` | รัฐเล็กอุดมสมบูรณ์ อ่อนโยนแต่มั่งคั่ง |
| ประเทศสีเขียวหม่นใต้ Lysenne | `Marrowen` | ดินแดนชายแดนเงียบขรึม มีป่าและหมอก |

| ประเทศสีชมพูใหญ่ใต้ Lacoss | `Rosvaria` | ราชรัฐกึ่งหรูหรา วัฒนธรรมเข้ม |
| ประเทศสีครีมใหญ่ตอนใต้ตอนกลาง | `Caldria` | รัฐเก่าแก่ อากาศอบอุ่น เสบียงดี |
| ประเทศสีเทาอมชมพูใต้ตะวันออก | `Demeris` | รัฐเงียบ สุขุม ใกล้ทะเลใต้ |
| ประเทศเล็กสีแดงหม่นใต้ Lacoss ฝั่งตะวันตก | `Vardane` | รัฐทหารเล็ก ดื้อและแข็ง |

| ประเทศเล็กสีม่วงใต้ Lacoss ตอนกลางค่อนไปตะวันออก | `Morvane` | รัฐขุนนางเก่า เคร่งพิธี |
| ประเทศสีน้ำเงินสดใต้ตะวันออกของ Lacoss | `Selvarn` | รัฐชายแดนคมเข้ม เหมาะเป็นด่านกันชน |
| ประเทศสีเขียวสดใต้ Aetherion | `Verdalis` | ดินแดนอุดมสมบูรณ์ ป่าและสมุนไพร |

## หมายเหตุเชิงโลก

* `Lacoss` ไม่ใช่ประเทศเหนือสุดของทวีป
* `บารอนแห่งแดนเหนือ` ของตระกูล Alcine หมายถึงผู้ครองเขตเหนือภายใน `Lacoss`
* ประเทศรองหลายแห่งควรมีบทบาทเป็นรัฐกันชน รัฐการค้า หรือรัฐที่ถูก Eryndor กลืนในอนาคต เพื่อให้แผนที่ไม่เป็นเพียงฉากหลัง
